# Batch Upload Guide

Batch upload is available at `/dashboard/batch-upload/` for Admin users only.

It is also linked from Django Admin at `/admin/` under the `Melodu Workflows` section.

## Scope

Supported modules:

- Categories
- Brands
- Suppliers
- Products
- Stock-In

Not supported:

- POS sales
- Audit logs
- Reports
- System logs

Those unsupported records must remain generated by controlled application workflows.

## File Formats

- `.csv`
- `.xlsx`

Files must include the exact columns for the selected upload target. Extra columns may be present, but missing target columns are rejected before the preview job is created.

## Workflow

1. Open `/dashboard/batch-upload/`.
2. Choose an upload target.
3. Upload a CSV or XLSX file.
4. Review the preview rows.
5. Edit rows with validation errors or wrong values.
6. Delete rows that should not be committed.
7. Commit valid selected rows.

Preview data is stored in the database as an upload job and upload rows, so the preview can be refreshed before commit.

## Commit Rules

- Invalid rows are never committed.
- Deleted rows are marked skipped.
- Category, brand, and supplier rows update or create records by `name`.
- Product rows update or create records by `product_code`.
- Stock-in rows always create new stock batches and never update existing batches.
- Stock-in rows use the existing `receive_stock()` service.
- Every committed stock-in row creates a stock batch, barcode image, QR image, inventory movement, and audit log.
- Every committed upload job creates a batch upload audit summary.

## Boolean Values

Boolean fields accept:

- True values: `TRUE`, `true`, `1`, `yes`, `y`, `active`
- False values: `FALSE`, `false`, `0`, `no`, `n`, `inactive`

Blank boolean values default to `TRUE`.

## Date And Number Values

- Dates must use `YYYY-MM-DD`.
- Decimal values must be valid non-negative decimal numbers.
- Quantity must be a whole number greater than zero.
- `min_stock` must be a whole number greater than or equal to zero.

## Schemas

### Categories

Columns:

- `name`
- `description`
- `is_active`

Required:

- `name`

Example:

```csv
name,description,is_active
Food,Pet food,TRUE
```

### Brands

Columns:

- `name`
- `description`
- `is_active`

Required:

- `name`

Example:

```csv
name,description,is_active
Melodu,House brand,TRUE
```

### Suppliers

Columns:

- `name`
- `contact_person`
- `phone`
- `telegram`
- `address`
- `notes`
- `is_active`

Required:

- `name`

Example:

```csv
name,contact_person,phone,telegram,address,notes,is_active
Pet Wholesale,Sophea,012345678,@supplier,Phnom Penh,,TRUE
```

### Products

Columns:

- `product_code`
- `original_barcode`
- `name`
- `category`
- `brand`
- `unit`
- `default_cost_price`
- `default_selling_price`
- `min_stock`
- `description`
- `is_active`

Required:

- `product_code`
- `name`

Validation:

- `product_code` is the update-or-create identifier.
- `category` must match an existing category name when provided.
- `brand` must match an existing brand name when provided.
- `original_barcode` must not be used by a different existing product.
- `original_barcode` must not be duplicated by another selected row in the same upload with a different product code.
- Product images are not included in Version 1 batch upload.
- `animal_type`, `life_stage`, and `tags` are **optional** (V4). Files without
  these columns still work. `animal_type`/`life_stage` use code values
  (case-insensitive), e.g. `CAT`, `ADULT`; invalid values are flagged in
  preview. `tags` is one cell separated by `;` or `,`; tags are created on
  demand. See `docs/PRODUCT_CLASSIFICATION_GUIDE.md`.

Example:

```csv
product_code,original_barcode,name,category,brand,unit,default_cost_price,default_selling_price,min_stock,description,animal_type,life_stage,tags,is_active
P001,8851234567890,Cat Food,Food,Melodu,Bag,1.50,2.50,5,,CAT,ADULT,Grain Free; Indoor,TRUE
```

### Stock-In

Columns:

- `product_code`
- `supplier`
- `quantity`
- `expiry_date`
- `actual_unit_cost`
- `landed_unit_cost`
- `selling_price`
- `note`

Required:

- `product_code`
- `supplier`
- `quantity`
- `expiry_date`
- `actual_unit_cost`
- `selling_price`

Optional:

- `landed_unit_cost`

Validation:

- Product must already exist.
- Product must be active.
- Product must have an original barcode.
- Supplier must already exist.
- Supplier must be active.
- Quantity must be greater than zero.
- Expiry date is required.

Example:

```csv
product_code,supplier,quantity,expiry_date,actual_unit_cost,landed_unit_cost,selling_price,note
P001,Pet Wholesale,10,2027-06-01,1.50,1.75,2.50,Initial stock
```

## CSV Templates

Template files are stored in `docs/batch_upload_templates/`:

- `categories.csv`
- `brands.csv`
- `suppliers.csv`
- `products.csv`
- `stock_in.csv`

The application also provides downloadable templates from `/dashboard/batch-upload/`.
