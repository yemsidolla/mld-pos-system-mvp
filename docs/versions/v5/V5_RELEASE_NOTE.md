# V5 Release Note — UI/UX Polish, Naming Cleanup, and Product Usability

## Summary

V5 improved dashboard usability: better navigation, audit visibility, consistent
lists, and workflow shortcuts. Mobile polish was a partial slice.

## What Changed

- Role-aware dashboard home
- Staff-friendly navigation labels
- Read-only audit log in dashboard
- Search and pagination on long lists
- Stock receiving → print shortcuts
- Shared list/filter consistency
- Mobile nav and table scroll improvements (partial)

## What Did Not Change

Sale logic, inventory services, auth/OIDC behavior, database schema.

## Business Value

Easier daily use for staff; fewer confusing dead-ends and inconsistent lists.

## Risk Level

Low–medium — template/CSS focused; test suite guarded regressions.

## Known Gaps

Full mobile redesign and complete staff satisfaction not achieved — V7 continues.

## Handoff to Next Version

V6 documentation/OIDC foundation; V7 UX cleanup completes V5's remaining polish.
