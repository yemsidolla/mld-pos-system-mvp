# V4 Release Note — User Management, Classification, Printing, and Admin Maintenance

## Summary

V4 made Melodu POS operable by a full store team with classification, branded
receipts, label templates, and safe maintenance tooling.

## What Changed

- Five roles and dashboard user management
- Product tags and classification fields
- Store settings and thermal receipt template
- Label template system and promotion labels
- Audited receipt reprint
- Safe CLI data reset with guards

## What Did Not Change

Core batch inventory and sale services; OIDC not production-default.

## Business Value

Managers can run staff access, print professionally, and maintain data safely.

## Risk Level

Medium — permissions and reset tooling are high-impact; tested at delivery.

## Known Gaps

Physical printer certification; OIDC deferred to V6.

## Handoff to Next Version

V5 — UI/UX polish and staff-facing naming cleanup.
